Enjab UI is the Enjab design system, published as a **shadcn registry**. Hand an agent
[`https://ui.enjab.ae/llms.txt`](https://ui.enjab.ae/llms.txt) and it can theme any
project to match Enjab with no other input.

- **Registry base:** `https://ui.enjab.ae/r/{name}.json`
- **Namespace:** `@enjab-ui`
- **Index of all items:** `https://ui.enjab.ae/r/registry.json`
- **Live showcase + changelog:** [ui.enjab.ae](https://ui.enjab.ae)

## Setup

Install the **theme first** — it sets the Enjab design tokens every component depends on.

```bash
npx shadcn@latest add https://ui.enjab.ae/r/theme.json
npx shadcn@latest add https://ui.enjab.ae/r/button.json
```

Or register the namespace in `components.json`, then add by name:

```json title="components.json"
{
  "registries": { "@enjab-ui": "https://ui.enjab.ae/r/{name}.json" }
}
```

```bash
npx shadcn@latest add @enjab-ui/button
```

## Fonts

Load these — the theme references them by name (`--font-heading`, `--font-sans`,
`--font-mono`):

- **Headings:** Inter (Display optical size) — Google Fonts.
- **Body / UI:** Satoshi — [Fontshare](https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700,900&display=swap).
- **Data (numbers, IDs, times):** Fragment Mono — Google Fonts (the `font-data` class).

## Components

The registry covers the whole tool surface. Install `theme` first, then add what you need.

| Item | What it is |
| --- | --- |
| `theme` | Enjab design tokens (colors, fonts, radius). **Install first.** |
| `button` | Pill button with a `navy` variant and a `loading` prop. |
| `alert` | In-page message box in four tones (success, info, warning, danger). |
| `status-pill` | Colored dot + label. Status is never color alone. |
| `stat-card` | KPI card with a mono value and trend delta. |
| `data-table` | The Enjab table, fully self-styled and identical everywhere. |
| `sidebar` / `dashboard-shell` / `page-header` | The dashboard chrome. |
| `sidebar-footer` | Required sidebar bottom: account block + the Enjab byline. |
| `app-mark` | A tool's OWN mark (gradient favicon square + name). |
| `favicon` | The code-generated favicon. Required in every project. |
| `enjab-byline` | "an Enjab product" byline. Required on every dashboard. |
| `logo` | The Enjab PARENT logo — only for the byline, never a tool's own brand. |
| `reveal` | Framer Motion scroll reveal. Landing pages only. |

## Core rules

<Callout title="Light mode only">
Never add a dark theme or `dark:` variants. Enjab has no reversed palette.
</Callout>

- **Color:** teal `#057C8B` is primary, navy `#1B3766` is depth. Always reference tokens
  (`bg-teal`, `text-navy`, `text-muted-foreground`), never hardcode hex.
- **Typography:** headings use Inter Display, body uses Satoshi, all numbers/IDs/times use
  Fragment Mono. Never put a heading in Satoshi.
- **Each tool shows its OWN mark** (favicon square + name) in the sidebar and navbar. The
  Enjab logo appears only in the "an Enjab product" byline.
- **Slow buttons give feedback:** any button whose action takes time must disable + show a
  spinner (`<Button loading={busy}>`). Never clickable and silent.
- **Feedback has three tools:** `alert` for persistent view-tied messages, a toast
  (sonner) for transient "it worked / it failed", `status-pill` for a single row's status.
- **Responsive:** landing pages are fully responsive (down to 360px); dashboards are
  desktop-optimized but must stay phone-usable. The shared chrome handles most of it.
- **Motion:** animations belong on landing pages only. Dashboards stay still.
