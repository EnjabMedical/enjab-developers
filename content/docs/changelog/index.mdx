## Updating a tool

To bring a tool up to date, see [Update an existing tool](/docs/update-an-existing-tool): one
prompt for [everything (UI + Auth)](/docs/update-an-existing-tool), or a focused
[UI](/docs/update-an-existing-tool/ui) or [Auth](/docs/update-an-existing-tool/auth) track.
Updates are not refactors, apply only what a tool has not adopted and leave the rest exactly
as it is.
